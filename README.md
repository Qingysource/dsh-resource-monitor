# dsh-resmon · DeepSeek Harness 资源监控面板

一个开箱即用的 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 插件:在窗口左下角提供**可拖动、可自定义**的资源监控面板,类任务管理器实时图表 + Token/费用统计,并尽可能接入 DeepSeek 官方数据。

![license](https://img.shields.io/badge/license-MIT-blue)

## 功能一览

### 自定义监控面板
- 面板默认空白,点「＋ 添加监控项目」按需添加,共 **8 类**:
  - **CPU / 内存**:实时曲线,支持「整机 / DSH 进程」两种口径切换
  - **磁盘**:任务管理器同款「活动时间 %」(读写请求占用时间百分比)+ 容量信息
  - **DSH 占用**:DSH 应用目录与数据目录的磁盘占用合计(启动即算,每 5 分钟刷新)
  - **网络**:上下行实时速率 + 总速率曲线
  - **GPU**:NVIDIA(nvidia-smi)与 AMD/Intel(Windows 性能计数器)双后端,3D 引擎利用率 + 显存
  - **Token 消耗**:本轮 / 会话 / 今日 / 累计 四口径切换,输入 / 输出 / 合计
  - **费用**:按「当前模型 + 推理等级 + 官方报价」计价,本轮 / 会话 / 今日 / 累计同屏展示,运行中附实时预计

### 费用与官方数据(以官方为准)
- 计价按 DeepSeek 官方报价表:**高峰/空闲双时段**(北京时间工作日 9:00–12:00、14:00–18:00 为高峰,其余半价;节假日保守按高峰计),缓存命中按命中价、写入按未命中价;`deepseek-flash` / `deepseek-v4-pro` 及遗留别名均支持,停用模型与未知模型按 v4-pro 高峰价兜底
- **今日费用**取值优先级:官方平台精确用量(账户登录,尽力而为)→ 小鲸鱼挂件账本(见下)→ 官方余额差观测 → 本地估算
- **官方余额**:通过 DSH 登录账户(充值 + 赠金)或 API Key(`/user/balance`)实时读取
- 底部一键直达**官方用量页**,最终以官方平台数据为准
- 历史回溯:插件会扫描会话持久化日志,把安装插件之前的 Token 与费用并入今日/累计统计,不重复计数

> 可选集成:若同时安装了 `dsh-whale-widget`(小鲸鱼挂件),今日费用会自动对齐小鲸鱼账本的「今日已用」,两边数字同步。

### 面板交互
- 按住标题栏自由拖动,位置自动记忆
- 可折叠为小胶囊,窗口缩放时自动校位(不会跑到窗口外)
- 底部信息:计算机名 + 系统版本号(如 `Win11 26H2 26300.9711`)+ 运行时长

## 安装

**方式一(推荐):本地目录安装**
```bash
git clone <本仓库地址> dsh-resmon
dsh plugin install ./dsh-resmon
# 或:桌面版「设置 → 插件 → 安装」选择该目录
```

**方式二:直接复制**
将整个目录放入插件工作区,用插件管理器安装目录即可。

安装后**重启 DeepSeek Harness 应用**(桌面端在启动时注入插件清单),左下角即出现空白小卡片,点「＋ 添加监控项目」开始配置。

## 环境要求

- DeepSeek Harness(桌面版 / Web 版)
- Node ≥ 22(需内建 `node:zlib` 的 Zstandard 支持,用于读取会话历史日志)
- Windows:全部监控项可用;其它平台:CPU/内存/磁盘/DSH 占用/Token/费用可用,网络与 GPU 自动降级显示「不可用」

插件**零第三方运行依赖**(仅 `@deepseek-ai/schemastery` 用于设置表单 schema),不收集、不上传任何数据;唯一的外部请求是 DeepSeek 官方余额接口(`https://api.deepseek.com/user/balance`,仅在配置了 API Key 时)与官方平台用量页链接。

## 设置(DSH 设置 → 插件 → 资源监控 → 配置)

插件声明了原生配置 schema,可在 DSH 设置中可视化编辑(保存后随 profile 补丁持久化):

| 分组 | 可编辑项 |
|---|---|
| 计价配置 | 空闲时段价格系数(高峰×系数)、default 兜底计价(JSON)、模型计价覆盖(JSON,如 `{"deepseek-flash":{"input":2,"cachedInput":0.04,"output":8}}`) |
| 官方数据源 | 模式(auto / apikey / account / off)、余额轮询间隔(15–600 秒) |
| 小鲸鱼账本 | 是否读取账本、自定义账本路径(默认 `~/.dsh/.dshw-usage.json`) |
| 采样节奏 | 网络/GPU 采样间隔秒、磁盘采样间隔秒、DSH 占用重算间隔分钟 |

## 数据口径说明(重要)

| 项目 | 口径 |
|---|---|
| 本轮 | 本地实时预测(会话日志 usage × 官方单价) |
| 今日 | 官方平台精确用量(可用时)→ 小鲸鱼账本 → 官方余额差 → 本地估算 |
| 累计 | **官方余额观测累计**(小鲸鱼账本逐日余额差聚合;账本不可用时回退本地估算) |
| 会话 | 本地估算(官方未按会话开放) |
| 官方余额 | DeepSeek 官方接口实时快照 |

- 官方公开接口只有余额快照,没有用量明细接口;费用以「余额观测」为主口径,受充值/赠金影响时余额上升会提示待校正。
- **最终以 DeepSeek 官方平台的用量页面为准**,面板底部提供直达链接。

## 技术实现

- Host 端(数据采集与统计):CPU/内存/磁盘/网络/GPU 采样、会话事件折叠(含费用)、历史日志回溯(多帧 zstd 会话文件解析)、官方数据源接入
- Client 端(面板 UI):`shell.overlay` 槽位 + React,主题 token 适配深色/浅色,中英双语
- 数据通道:两条宿主鉴权 Fetch 路由(`/api/dsh-resmon/stats`、`/api/dsh-resmon/usage`)
- 持久化:宿主存储域(累计/每日统计、余额观测基线、会话去重序号)
